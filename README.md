
# Predicting Healthcare Insurance Costs with Python

**Solving Real-World Data Science Problems with Python!**  
This project demonstrates how to predict individual health insurance costs using Python and machine learning. It follows a complete workflow from cleaning and visualizing data to building and evaluating a regression model.  

## Project Overview
This project uses a real-world dataset to predict health insurance costs based on features such as age, sex, BMI, smoking status, and region.

  It teaches:
- Data handling and cleaning with pandas
- Exploratory Data Analysis (EDA) and visualizations with matplotlib and seaborn
- Preparing data for machine learning (encoding categorical variables, train-test split)
- Building and evaluating a linear regression model with scikit-learn
- Hands-on predictive modeling experience


## Dataset
The dataset contains the following columns:

| Column   | Description                               |
|----------|-------------------------------------------|
| age      | Age of the individual                     |
| sex      | Gender of the individual (male/female)    |
| bmi      | Body Mass Index                           |
| children | Number of children/dependents             |
| smoker   | Smoking status (yes/no)                   |
| region   | Residential area                          |
| charges  | Health insurance cost (target variable)   |

Dataset source: [Kaggle: Medical Cost Personal Dataset](https://www.kaggle.com/datasets/mirichoi0218/insurance)
